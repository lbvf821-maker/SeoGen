# 🚀 Инструкция по настройке OpenAI Assistant для телеграм-бота ВЭМ

## 📁 Файлы в комплекте

1. **openai_assistant_prompt_fixed.json** — основной исправленный промпт (рекомендуется)
2. **openai_assistant_prompt_simple.json** — упрощенная версия (если основной не работает)
3. **knowledge_base_for_file_search.txt** — база знаний для File Search
4. **prompt_analysis_and_fixes.md** — детальный анализ проблем и исправлений

---

## 🔧 Шаг 1: Создание Assistant в OpenAI

### 1.1 Перейдите на платформу OpenAI
Откройте: https://platform.openai.com/assistants/

### 1.2 Создайте нового Assistant
Нажмите **"Create"** и заполните:

- **Name:** ВЭМ | Продажа инструментальной стали
- **Model:** `gpt-4-turbo` или `gpt-4o` (НЕ gpt-3.5-turbo!)
- **Temperature:** `0.4` (баланс точности и естественности)
- **Instructions:** Скопируйте содержимое файла `openai_assistant_prompt_fixed.json`

### 1.3 Включите инструменты (Tools)
Активируйте:
- ✅ **File Search** (обязательно!)
- ❌ Code Interpreter (не нужен)
- ❌ Function calling (настроите позже для Albato, если нужно)

---

## 📚 Шаг 2: Загрузка базы знаний

### 2.1 Подготовьте файл
Используйте `knowledge_base_for_file_search.txt` из комплекта.

### 2.2 Загрузите в File Search
1. В разделе Assistant перейдите на вкладку **"Files"**
2. Нажмите **"Upload files"**
3. Выберите `knowledge_base_for_file_search.txt`
4. После загрузки убедитесь, что статус: ✅ **Ready**

### 2.3 Привяжите к Assistant
1. Вернитесь к настройкам Assistant
2. В разделе **"File Search"** выберите загруженный файл
3. Сохраните изменения

## 🔗 Шаг 3: Интеграция с Wazzup24 и Albato

### 3.1 Настройка Wazzup24
1. Подключите Telegram канал к Wazzup24
2. В настройках канала включите **"API Integration"**
3. Настройте отправку сообщений на OpenAI Assistant API:
   - **Endpoint:** `https://api.openai.com/v1/threads/{thread_id}/messages`
   - **Method:** POST
   - **Headers:**
     ```json
     {
       "Authorization": "Bearer YOUR_OPENAI_API_KEY",
       "Content-Type": "application/json",
       "OpenAI-Beta": "assistants=v2"
     }
     ```

### 3.2 Настройка Albato для парсинга лидов
1. Создайте новый сценарий в Albato: https://new.albato.ru
2. **Триггер:** Webhook (входящее сообщение от Wazzup24)
3. **Фильтр:** Текст содержит `[systemTextByAi:`
4. **Действие:** Извлечение JSON

#### Настройка извлечения JSON:
```javascript
// Регулярное выражение для извлечения JSON
const regex = /\[systemTextByAi:\s*(.+?)\]/;
const match = inputText.match(regex);

if (match && match[1]) {
  const jsonData = JSON.parse(match[1]);
  return jsonData; // {trigger, name, phone, summarize, ...}
}
```

5. **Далее:** Отправка в CRM / Google Sheets / Email / и т.д.

## 🐛 Шаг 5: Устранение проблем

### Проблема 1: Модель не выдает адрес
**Причина:** File Search не находит информацию или правило "уточним в КП" перекрывает ответ

**Решение:**
1. Убедитесь, что `knowledge_base_for_file_search.txt` загружен и статус ✅ Ready
2. Проверьте, что в Instructions есть правило:
   ```
   "ТОЧНЫЕ ФАКТЫ: адрес склада → Нижний Новгород, Ореховская, 1"
   ```
3. Если не помогает, добавьте в самое начало Instructions:
   ```
   КРИТИЧЕСКИ ВАЖНО: При вопросе "где склад?" или "какой адрес?" ВСЕГДА отвечай:
   "Нижний Новгород, Ореховская, 1"
   ```

---

### Проблема 2: Модель не запрашивает имя после телефона
**Причина:** Логика фаз не работает или модель gpt-3.5-turbo (слабая)

**Решение:**
1. Проверьте модель: должна быть **gpt-4-turbo** или **gpt-4o**
2. Снизьте Temperature до **0.3**
3. Добавьте в начало Instructions:
   ```
   АБСОЛЮТНОЕ ПРАВИЛО: Если получен ТОЛЬКО телефон → следующим сообщением запроси имя.
   Если получено ТОЛЬКО имя → следующим сообщением запроси телефон.
   ```

---

### Проблема 3: [systemTextByAi: {...}] не выводится
**Причина:** Формат или экранирование JSON

**Решение:**
1. Проверьте, что в Instructions формат такой:
   ```json
   [systemTextByAi: {"trigger":"NEWLEAD","name":"{name}","phone":"{phone}",...}]
   ```
   (БЕЗ символов `%%`)

2. Убедитесь, что в фазе подтверждения заявки есть инструкция вывести этот текст

3. Если не помогает, используйте **Function Calling** вместо текстового вывода:
   - Создайте функцию `send_lead_to_albato`
   - Параметры: name, phone, summarize, quest, и т.д.
   - Настройте Albato на получение Function Call

---

### Проблема 4: Модель слишком многословна
**Причина:** Temperature высокая или нет ограничения на длину

**Решение:**
1. Снизьте Temperature до **0.3-0.4**
2. В Instructions добавьте в tone: **"Максимум 400 символов в ответе"**
3. Установите в настройках API: **max_tokens = 800**

---

### Проблема 5: Albato не получает данные
**Причина:** Wazzup24 не передает сообщения или Albato не парсит

**Решение:**
1. Проверьте логи Wazzup24: доходят ли сообщения с `[systemTextByAi:`?
2. В Albato в сценарии добавьте действие **"Log to Console"** перед парсингом
3. Проверьте, что webhook в Albato активен и URL корректен
4. Используйте тестовое сообщение для отладки:
   ```
   [systemTextByAi: {"trigger":"TEST","name":"Тест","phone":"+79001234567"}]
   ```

## 📊 Шаг 6: Мониторинг и оптимизация

### Что отслеживать:
1. **Конверсия в лид:** % диалогов, где получены имя + телефон
2. **Время до лида:** Среднее количество сообщений до получения контактов
3. **Качество ответов:** Довольны ли клиенты ответами на вопросы?
4. **Ошибки парсинга:** Процент лидов, где Albato не смог распарсить JSON

### Как улучшить:
- Если конверсия низкая → упростите сбор контактов (меньше вопросов до запроса имени/телефона)
- Если ответы неточные → дополните базу знаний недостающей информацией
- Если клиенты жалуются на длину → снизьте Temperature и ограничьте max_tokens
