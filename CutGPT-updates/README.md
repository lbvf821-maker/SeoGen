# CutGPT - 3D Guillotine Cutting Algorithm

## Описание
Веб-приложение для 3D раскроя металлических блоков по алгоритму guillotine cutting.
Реализовано согласно спецификации из документа "3D Guillotine Cutting Algorithm Implementation.pdf".

## Возможности
- ✅ 3D алгоритм guillotine резки
- ✅ Поддержка приоритетов деталей
- ✅ Учёт толщины пропила (kerf)
- ✅ 6 ориентаций для каждой детали
- ✅ 3D визуализация результатов
- ✅ Экспорт результатов в CSV
- ✅ Управление базой материнских блоков
- ✅ Расчёт утилизации и отходов

## Запуск

### Локальный запуск
```bash
cd CutGPT
python3 server.py
```

Сервер запустится на http://127.0.0.1:8000

### Запуск на другом порту
```bash
python3 server.py --host 0.0.0.0 --port 8080
```

## Использование

### 1. Добавление материнских блоков
Можно добавить блоки:
- Вручную через форму (BlockID, X, Y, Z, Kerf, SteelGrade)
- Импортом из Excel/CSV (формат: BlockID, X, Y, Z, Kerf, SteelGrade)

### 2. Добавление деталей
Вставьте список деталей в формате:
```
GroupID,PartID,X,Y,Z,Quantity,Priority
GroupA,Part1,50,40,20,2,1
GroupB,Part2,30,20,10,1,0
```

### 3. Расчёт раскроя
1. Нажмите "Разобрать детали"
2. Выберите материнские блоки из списка (можно несколько)
3. Нажмите "Рассчитать раскрой"

### 4. Результаты
- 3D визуализация размещения деталей
- Таблица размещённых деталей с координатами
- Таблица остатков (отходов)
- Экспорт в CSV: отчёт, размещения, остатки, шаги резов

## API

### GET /api/stocks
Получить список материнских блоков

### POST /api/stocks
Сохранить список блоков
```json
{
  "stocks": [
    {
      "id": "S1",
      "X": 200,
      "Y": 150,
      "Z": 120,
      "Kerf": 1.0,
      "SteelGrade": "Steel_A"
    }
  ]
}
```

### POST /api/solve
Рассчитать раскрой
```json
{
  "parts": [
    {
      "PartID": "Part1",
      "X": 50,
      "Y": 40,
      "Z": 20,
      "Quantity": 1,
      "Priority": 1
    }
  ],
  "selectedStockIds": ["S1"]
}
```

## Алгоритм

Реализован согласно PDF спецификации:
1. **Приоритизация**: сортировка деталей по приоритету (1 > 0) и объёму (больше → меньше)
2. **Подбор ориентации**: проверка всех 6 ориентаций детали для минимизации отходов
3. **Последовательные резы**: до 3 резов (X, Y, Z) для извлечения детали
4. **Учёт kerf**: вычитание толщины пропила при каждом резе
5. **Рекурсивная обработка остатков**: остатки обрабатываются для размещения следующих деталей
